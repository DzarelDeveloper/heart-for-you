# ❤️ Heart Protocol

Sebuah aplikasi web interaktif yang dirancang dengan tema *cyberpunk/terminal*. Proyek ini menggabungkan estetika teknologi dengan animasi visual yang dinamis untuk menciptakan pengalaman yang unik.

## 🔗 Live Demo
Cek aplikasinya di sini: [https://heart-for-you-labuda.netlify.app/](https://heart-for-you-labuda.netlify.app/)

## ✨ Fitur Utama

- **Multiverse Scanning Intro**: Narasi pembuka yang mencari sinyal unik di seluruh multiverse menggunakan efek typewriter.
- **Dynamic Heart Canvas**: Ribuan teks yang bergerak membentuk detak jantung secara dinamis menggunakan HTML5 Canvas.
- **Interactive Elements**: 
  - Teks utama di tengah hati yang merespons klik pengguna.
  - Saat diklik, teks di latar belakang akan berubah secara acak dengan berbagai pesan interaktif.
  - Efek kilatan cahaya putih dan transisi warna saat interaksi terjadi.
- **Atmospheric Music**: Audio latar yang terintegrasi secara halus (dimulai setelah interaksi pengguna) dengan kontrol volume manual.
- **Responsive Design**: Tampilan yang menyesuaikan dengan berbagai ukuran layar, dioptimalkan untuk desktop dan mobile.

## 🚀 Teknologi yang Digunakan

- **HTML5 Canvas**: Untuk sistem partikel teks dan animasi bentuk hati.
- **Tailwind CSS**: Untuk UI yang modern, responsif, dan sistem grid.
- **JavaScript (Vanilla)**: Manajemen state aplikasi, logika animasi, dan kontrol audio.
- **Lucide Icons**: Set ikon untuk kontrol UI.
- **Google Fonts**: Menggunakan 'Fira Code' untuk nuansa terminal dan 'Inter' untuk elemen UI.

## 🛠️ Cara Menjalankan Secara Lokal

1. Clone repositori ini:
   ```bash
   git clone https://github.com/DzarelDeveloper/heart-for-you.git
   ```
2. Masuk ke direktori proyek:
   ```bash
   cd heart-for-you
   ```
3. Jalankan melalui local server (seperti Live Server di VS Code) atau buka langsung file `index.html` di browser.
